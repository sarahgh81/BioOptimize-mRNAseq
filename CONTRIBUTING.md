# Contributing to BioOptimize-mRNAseq

Thank you for your interest in improving the pipeline!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes and add tests
4. Run `pytest` and `ruff check`
5. Open a Pull Request

## Guidelines

- Keep the research-use-only spirit
- Prefer clear, documented code over clever one-liners
- Update docs when adding features
- All new modules should include type hints and docstrings

## Ideas Welcome

- Real STAR/HISAT2 subprocess wrappers
- Interactive Streamlit dashboard
- LLM-powered result interpretation
- Support for single-cell RNA-seq
- Benchmarking suite
